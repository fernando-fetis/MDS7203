\section*{Adaptadores}
\begin{enumerate}[{\bf P1.}]
	\item ControlNet es una técnica que permite condicionar modelos de difusión preentrenados con información adicional. Mencione 3 tipos de condicionamiento que se pueden realizar utilizando ControlNet para guiar la generación de imágenes.
	\item DreamBooth es una técnica de fine tuning que permite personalizar modelos de difusión para generar imágenes de un sujeto o concepto específico (\textit{subject-driven generation}). Explique cómo se realiza el fine tuning y la generación de imágenes personalizadas utilizando DreamBooth.
\end{enumerate}

	\item Mencione 3 diferencias entre los modelos de difusión y los modelos de flow matching.
\end{enumerate}
