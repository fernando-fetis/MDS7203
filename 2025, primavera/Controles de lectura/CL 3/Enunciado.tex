\section*{Retrieval-augmented generation}
\begin{enumerate}[{\bf P1.}]
	\item Dado un conjunto de documentos, $M=(S_1,\ldots,S_N)\subset\mathcal{V}^*$ (interpretado como \textit{memoria externa}), explique cómo se realiza RAG usando estos documentos para responder una query $q\in\mathcal{V}^*$ realizada por un usuario a un LLM. Recuerde que para RAG es necesario utilizar un modelo de embedding $f:\mathcal{V}^*\to\R^d$ (p.g. BERT) que codifique secuencias de tokens en vectores de $\R^d$, y un modelo de lenguaje $g:\mathcal{V}^*\to\mathcal{V}^*$ (p.g. GPT) que genera texto a partir de un \textit{prompt} dado como entrada.
\end{enumerate}

\section*{Redes generativas adversarias}
\begin{enumerate}[{\bf P1.}]
	\item ¿Cuál es la función del generador y del discriminador en una GAN? ¿Por qué se dice que ambos modelos compiten entre sí?
	\item Las GANs son modelos de variable latente (recordar que el generador es una red bayesiana $p_\theta(x,z)=p(z)p_\theta(x|z)$, con $p(z)\sim\mathcal{N}{(0,\text{I}_L)}$ y $p_\theta(x|z)\sim\delta_{G_\theta(z)}(x)$). Por qué esto no permite, en la práctica, entrenar una GAN usando el enfoque de máxima verosimilitud?
\end{enumerate}
